# IP 情报服务配置

网关只连接一个自建兼容接口；第三方来源、轮换、缓存、配额和熔断由独立服务管理。接口合同见 [集中调度设计](audit-ip-central-orchestration.md)。实际域名、服务器配置、启用来源及查询预算记录在本地环境文档。

## 网关后台

入口：审计日志 → 安全监控 → 监控设置 → 自建 IP 情报服务。需要 Root 权限并完成正常二次验证。

- 接口地址：填写实际自建服务的 HTTPS 地址，不在代码中固定部署域名。
- API Key：自建服务访问密钥，留空保留已配置值；只有勾选“清除已保存密钥”才删除。
- 每日查询上限：限制网关向自建服务发送的请求；第三方限额由自建服务器单独管理。
- 允许的内网主机：仅私有兼容服务需要精确填写；公网域名不需要。不能关闭 HTTPS 或 SSRF 检查。

后台不再添加 ProxyCheck、ipapi.is 或 IPinfo，也不保存它们的密钥。旧版多源配置必须先迁移到独立服务，再收敛为一个接口；历史审计记录不改写。开启 IP 情报时必须有且仅有一个启用的自建接口。

## 健康与判断范围

网关健康区显示自建服务状态；查询返回的来源、证据和有效期用于告警回查。失败、缺失和过期字段保持未知，不填充正常结论。

IP 是网络出口，不能单独证明人员身份。位置精度不足时不判定不可能旅行；VPN、Tor 和信誉线索只辅助排查，不自动封号或阻断 AI 转发。
