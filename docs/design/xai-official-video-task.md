# xAI 官方视频任务支持

xAI 官方视频（`grok-imagine-video`、`grok-imagine-video-1.5`，渠道类型 `ChannelTypeXai = 48`）由内置任务插件 `plugins/tasks/xai/plugin.js` 提供，与第三方 Seedance 2.0 插件共用一份设计文档：

- [task-plugins-xai-sd2.md](./task-plugins-xai-sd2.md)

该文档包含请求转换与输入限制、`xai_video_units` 计费倍率与官方价格折算、表达式计费事实、轮询状态映射、旧平台 `"48"` 任务兼容、Main Chain Impact 与测试说明。
