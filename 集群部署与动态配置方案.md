## 1. 集群部署架构

### 1.1 问题分析

在集群环境中，定时任务会面临以下问题：

```
问题1: 任务重复执行
┌─────────┐  ┌─────────┐  ┌─────────┐
│ Node A  │  │ Node B  │  │ Node C  │
│ Master? │  │ Master? │  │ Master? │
└─────────┘  └─────────┘  └─────────┘
     ▼             ▼             ▼
  [定时任务]   [定时任务]   [定时任务]  ❌ 重复三遍

问题2: 选主机制不明确
     哪个节点才是Master?
     如果Master宕机怎么办?

问题3: 定时参数不统一
     各节点的参数配置不一致
     无法动态调整
```

## 2. 核心机制设计

### 2.1 分布式锁机制

**使用数据库实现的简单分布式锁**：

```sql
-- 分布式锁表
CREATE TABLE distributed_lock (
  id INT PRIMARY KEY AUTO_INCREMENT,
  lock_key VARCHAR(128) UNIQUE NOT NULL COMMENT '锁标识',
  owner VARCHAR(128) COMMENT '节点ID (hostname:pid)',
  acquired_at BIGINT COMMENT '获取时间',
  expires_at BIGINT COMMENT '过期时间',
  created_at BIGINT,
  updated_at BIGINT,
  
  KEY idx_key_expires (lock_key, expires_at)
);
```

**锁的获取逻辑**：

```go
// 尝试获取锁（带超时）
func (l *DistributedLock) TryAcquire(lockKey string, ownerID string, ttlSeconds int) (bool, error) {
    now := time.Now().Unix()
    expiresAt := now + int64(ttlSeconds)
    
    // 1. 先删除过期的锁
    db.Where("lock_key = ? AND expires_at < ?", lockKey, now).Delete(&Lock{})
    
    // 2. 尝试插入（依赖UNIQUE约束）
    result := db.Create(&Lock{
        LockKey:   lockKey,
        Owner:     ownerID,
        AcquiredAt: now,
        ExpiresAt: expiresAt,
    })
    
    // 3. 如果插入失败，说明锁已被其他节点持有
    if result.Error != nil {
        return false, nil  // 锁已被占用，这不是错误
    }
    
    return true, nil
}

// 释放锁
func (l *DistributedLock) Release(lockKey string, ownerID string) error {
    return db.Where("lock_key = ? AND owner = ?", lockKey, ownerID).
        Delete(&Lock{}).Error
}
```

**在应用中的使用**：

```go
func ExecuteMasterTask(taskName string) error {
    nodeID := getNodeID()  // hostname + pid
    lockKey := "task_" + taskName
    
    // 尝试获取锁（5分钟超时）
    acquired, err := distributedLock.TryAcquire(lockKey, nodeID, 300)
    if err != nil {
        return err
    }
    
    if !acquired {
        log.Printf("Lock not acquired for %s, skipping", taskName)
        return nil
    }
    
    // 获得了锁，执行任务
    defer distributedLock.Release(lockKey, nodeID)
    
    // ... 执行实际的任务 ...
    log.Printf("Executing master task: %s", taskName)
    return executeTask(taskName)
}
```

### 2.2 动态配置管理

**配置存储表**：

```sql
CREATE TABLE scheduler_config (
  id INT PRIMARY KEY AUTO_INCREMENT,
  task_name VARCHAR(128) UNIQUE NOT NULL COMMENT '任务名称',
  
  -- 执行参数
  enabled TINYINT DEFAULT 1 COMMENT '是否启用',
  interval_seconds INT COMMENT '执行间隔（秒）',
  timeout_seconds INT COMMENT '任务超时时间（秒）',
  requires_master TINYINT DEFAULT 0 COMMENT '是否仅在Master执行',
  
  -- 执行记录
  last_run_time BIGINT COMMENT '上次执行时间',
  last_run_status VARCHAR(32) COMMENT 'success, failed, timeout',
  last_error TEXT COMMENT '上次错误信息',
  next_run_time BIGINT COMMENT '下次计划执行时间',
  
  -- 配置管理
  created_at BIGINT,
  updated_at BIGINT,
  updated_by VARCHAR(128) COMMENT '最后更新者',
  
  UNIQUE KEY uniq_task_name (task_name)
);
```

### 2.3 配置加载和热更新

**Service 层**：

```go
package service

import (
    "sync"
    "time"
    "new-api-er/model"
    "new-api-er/common"
)

type SchedulerConfigService struct {
    cache      map[string]*model.SchedulerConfig
    cacheLock  sync.RWMutex
    cacheTime  time.Time
    cacheTTL   time.Duration
}

var schedulerConfigService = &SchedulerConfigService{
    cache:    make(map[string]*model.SchedulerConfig),
    cacheTTL: 1 * time.Minute,  // 配置缓存1分钟
}

// 获取配置（带缓存）
func (s *SchedulerConfigService) GetConfig(taskName string) (*model.SchedulerConfig, error) {
    s.cacheLock.RLock()
    
    // 检查缓存是否有效
    if time.Since(s.cacheTime) < s.cacheTTL {
        if config, ok := s.cache[taskName]; ok {
            s.cacheLock.RUnlock()
            return config, nil
        }
    }
    s.cacheLock.RUnlock()
    
    // 缓存过期或不存在，重新加载
    return s.LoadConfigFromDB(taskName)
}

// 从数据库加载配置
func (s *SchedulerConfigService) LoadConfigFromDB(taskName string) (*model.SchedulerConfig, error) {
    var config model.SchedulerConfig
    
    err := common.DB.Where("task_name = ?", taskName).First(&config).Error
    if err != nil {
        return nil, err
    }
    
    // 更新缓存
    s.cacheLock.Lock()
    s.cache[taskName] = &config
    s.cacheTime = time.Now()
    s.cacheLock.Unlock()
    
    return &config, nil
}

// 重新加载所有配置（热更新）
func (s *SchedulerConfigService) RefreshAllConfigs() error {
    var configs []model.SchedulerConfig
    
    err := common.DB.Find(&configs).Error
    if err != nil {
        return err
    }
    
    s.cacheLock.Lock()
    defer s.cacheLock.Unlock()
    
    s.cache = make(map[string]*model.SchedulerConfig)
    for i := range configs {
        s.cache[configs[i].TaskName] = &configs[i]
    }
    s.cacheTime = time.Now()
    
    common.LogInfof("Refreshed %d scheduler configs", len(configs))
    return nil
}

// 更新配置
func (s *SchedulerConfigService) UpdateConfig(taskName string, updates map[string]interface{}) error {
    updates["updated_at"] = time.Now().Unix()
    
    err := common.DB.Model(&model.SchedulerConfig{}).
        Where("task_name = ?", taskName).
        Updates(updates).Error
    
    if err == nil {
        // 清空缓存，强制重新加载
        s.cacheLock.Lock()
        delete(s.cache, taskName)
        s.cacheTime = time.Time{}  // 重置时间，强制刷新
        s.cacheLock.Unlock()
    }
    
    return err
}
```

## 3. 统一的定时任务管理器

### 3.1 任务调度器设计

```go
// service/task_scheduler.go

package service

import (
    "context"
    "fmt"
    "sync"
    "time"
    "new-api-er/common"
)

type TaskScheduler struct {
    tasks      map[string]*ScheduledTask
    taskLock   sync.RWMutex
    
    nodeID     string
    running    bool
    stopChan   chan struct{}
}

type ScheduledTask struct {
    Name           string
    RequiresMaster bool
    Handler        func(context.Context) error
    
    lastRun       time.Time
    lastError     error
}

var taskScheduler *TaskScheduler

func InitTaskScheduler() {
    nodeID := fmt.Sprintf("%s:%d", getHostname(), os.Getpid())
    
    taskScheduler = &TaskScheduler{
        tasks:    make(map[string]*ScheduledTask),
        nodeID:   nodeID,
        stopChan: make(chan struct{}),
    }
}

// 注册任务
func RegisterTask(name string, requiresMaster bool, handler func(context.Context) error) {
    taskScheduler.taskLock.Lock()
    defer taskScheduler.taskLock.Unlock()
    
    taskScheduler.tasks[name] = &ScheduledTask{
        Name:           name,
        RequiresMaster: requiresMaster,
        Handler:        handler,
    }
    
    common.LogInfof("Registered task: %s (requiresMaster: %v)", name, requiresMaster)
}

// 启动调度器主循环
func (ts *TaskScheduler) Start() {
    if ts.running {
        return
    }
    
    ts.running = true
    
    go func() {
        ticker := time.NewTicker(10 * time.Second)  // 每10秒检查一次
        defer ticker.Stop()
        
        for {
            select {
            case <-ts.stopChan:
                return
            case <-ticker.C:
                ts.checkAndExecute()
            }
        }
    }()
    
    common.LogInfof("Task scheduler started (nodeID: %s)", ts.nodeID)
}

func (ts *TaskScheduler) Stop() {
    ts.running = false
    close(ts.stopChan)
}

// 检查并执行任务
func (ts *TaskScheduler) checkAndExecute() {
    ts.taskLock.RLock()
    tasks := make([]*ScheduledTask, 0, len(ts.tasks))
    for _, task := range ts.tasks {
        tasks = append(tasks, task)
    }
    ts.taskLock.RUnlock()
    
    for _, task := range tasks {
        // 获取任务配置
        config, err := schedulerConfigService.GetConfig(task.Name)
        if err != nil {
            common.LogWarnf("Failed to get config for task %s: %v", task.Name, err)
            continue
        }
        
        // 检查任务是否启用
        if config.Enabled != 1 {
            continue
        }
        
        // 检查是否到了执行时间
        now := time.Now().Unix()
        if now < config.NextRunTime {
            continue
        }
        
        // 如果是Master任务，需要争夺分布式锁
        if task.RequiresMaster {
            lockKey := fmt.Sprintf("task_%s", task.Name)
            acquired, _ := distributedLock.TryAcquire(lockKey, ts.nodeID, int(config.TimeoutSeconds))
            
            if !acquired {
                common.LogDebugf("Could not acquire lock for master task: %s", task.Name)
                continue
            }
            
            // 执行任务
            ts.executeTask(task, config)
            
            // 释放锁
            distributedLock.Release(lockKey, ts.nodeID)
        } else {
            // 非Master任务，可以直接执行（但应该避免重复执行，可以用其他机制）
            ts.executeTask(task, config)
        }
    }
}

// 执行单个任务
func (ts *TaskScheduler) executeTask(task *ScheduledTask, config *model.SchedulerConfig) {
    ctx, cancel := context.WithTimeout(
        context.Background(),
        time.Duration(config.TimeoutSeconds)*time.Second,
    )
    defer cancel()
    
    common.LogInfof("Executing task: %s", task.Name)
    
    startTime := time.Now()
    err := task.Handler(ctx)
    duration := time.Since(startTime)
    
    // 记录执行结果
    status := "success"
    if err != nil {
        status = "failed"
        common.LogErrorf("Task %s failed: %v (duration: %s)", task.Name, err, duration)
    } else {
        common.LogInfof("Task %s completed successfully (duration: %s)", task.Name, duration)
    }
    
    // 更新数据库
    nextRunTime := time.Now().Unix() + int64(config.IntervalSeconds)
    updates := map[string]interface{}{
        "last_run_time":   startTime.Unix(),
        "last_run_status": status,
        "next_run_time":   nextRunTime,
    }
    
    if err != nil {
        updates["last_error"] = err.Error()
    }
    
    schedulerConfigService.UpdateConfig(task.Name, updates)
}

// 强制立即执行任务（用于DEBUG或管理接口）
func (ts *TaskScheduler) ExecuteNow(taskName string) error {
    ts.taskLock.RLock()
    task, ok := ts.tasks[taskName]
    ts.taskLock.RUnlock()
    
    if !ok {
        return fmt.Errorf("task not found: %s", taskName)
    }
    
    config, err := schedulerConfigService.GetConfig(taskName)
    if err != nil {
        return err
    }
    
    ts.executeTask(task, config)
    return nil
}

// 获取任务执行状态（用于监控和调试）
func (ts *TaskScheduler) GetTaskStatus(taskName string) (*TaskStatus, error) {
    config, err := schedulerConfigService.GetConfig(taskName)
    if err != nil {
        return nil, err
    }
    
    return &TaskStatus{
        TaskName:       config.TaskName,
        Enabled:        config.Enabled == 1,
        Interval:       config.IntervalSeconds,
        LastRunTime:    time.Unix(config.LastRunTime, 0),
        LastRunStatus:  config.LastRunStatus,
        LastError:      config.LastError,
        NextRunTime:    time.Unix(config.NextRunTime, 0),
    }, nil
}
```

### 5.2 更新配置

type UpdateConfigRequest struct {
    Enabled          *int    `json:"enabled"`
    IntervalSeconds  *int    `json:"interval_seconds"`
    TimeoutSeconds   *int    `json:"timeout_seconds"`
}

func UpdateTaskConfig(c *gin.Context) {
    taskName := c.Param("task_name")
    
    var req UpdateConfigRequest
    if err := c.BindJSON(&req); err != nil {
        c.JSON(400, gin.H{"error": err.Error()})
        return
    }
    
    updates := make(map[string]interface{})
    if req.Enabled != nil {
        updates["enabled"] = *req.Enabled
    }
    if req.IntervalSeconds != nil {
        updates["interval_seconds"] = *req.IntervalSeconds
    }
    if req.TimeoutSeconds != nil {
        updates["timeout_seconds"] = *req.TimeoutSeconds
    }
    
    err := service.schedulerConfigService.UpdateConfig(taskName, updates)
    if err != nil {
        c.JSON(500, gin.H{"error": err.Error()})
        return
    }
    
    c.JSON(200, gin.H{"success": true})
}
```

  -H "Authorization: Bearer $ADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "interval_seconds": 1800
  }'

# 3. 验证更新
curl -X GET "http://localhost:8080/api/admin/scheduler/config/GroupStatusAggregation"
```

**效果**：所有节点在10秒内感知到配置变化，下一个检查周期时生效（不需要重启）

### 6.3 场景：一个Master节点故障，自动转移任务

```
时间轴：
T0   - Node A (Master) 获得 GroupStatusAggregation 锁
T0+5min - Node A 故障，数据库连接丢失

T0+5min+10s - Node B 的任务调度器检查配置
           - 发现 GroupStatusAggregation 的下次运行时间已到达
           - 尝试获取 task_GroupStatusAggregation 锁
           - 因为Node A故障，它的锁超时(5分钟)
           - Node B 成功获得锁
           - Node B 执行 GroupStatusAggregation 任务

T0+10min - Node A 恢复，重新加入集群
         - 下次的 GroupStatusAggregation 执行时
         - Node A/B/C 都竞争，锁被其中一个获得
```

**注意**：锁的超时时间应该 >= 任务的最大执行时间

```
task_timeout = 300s (5分钟)
lock_ttl = max(300, 600) = 600s (至少10分钟)
```

## 9. 故障排查指南

### 问题：任务从未执行

**排查步骤**：
```bash
# 1. 检查配置是否启用
SELECT * FROM scheduler_config WHERE task_name = 'GroupStatusAggregation';
# enabled 应该为 1

# 2. 检查下次运行时间是否已到
SELECT now(), next_run_time FROM scheduler_config 
WHERE task_name = 'GroupStatusAggregation';

# 3. 查看任务调度器日志
tail -f logs/app.log | grep "Task scheduler"

# 4. 如果是Master任务，检查是否能获得分布式锁
SELECT * FROM distributed_lock WHERE lock_key = 'task_GroupStatusAggregation';
# 如果有记录，说明被其他节点持有
```

### 问题：Master任务在多个节点同时执行

**根本原因**：分布式锁机制失效

**排查步骤**：
```bash
# 1. 检查分布式锁表是否存在
SHOW TABLES LIKE 'distributed_lock';

# 2. 检查UNIQUE约束是否生效
SHOW CREATE TABLE distributed_lock\G

# 3. 查看正在持有的锁
SELECT * FROM distributed_lock WHERE expires_at > UNIX_TIMESTAMP();

# 4. 检查节点ID是否唯一
# 在所有节点执行
curl http://localhost:8080/api/admin/node/info
# node_id 应该不同
```

### 问题：配置更新后任务还是用旧的时间间隔

**原因**：配置缓存未刷新

**解决方案**：
```bash
# 方案1：等待1分钟（缓存TTL）

# 方案2：手动刷新配置缓存
curl -X POST "http://localhost:8080/api/admin/scheduler/refresh-config" \
  -H "Authorization: Bearer $ADMIN_TOKEN"

# 方案3：重启应用
```
